SIS vs D2L Course Gap

Upload a SIS course list CSV, pick the D2L semester, and see which sections are not present as course offerings in Brightspace.

How matching works
  • COURSE_CODE (SIS export): This is the main column we compare to each Brightspace offering’s Code under the semester you pick. Values often include the term (for example ABS-101W-FA818-26/FA) while D2L may store only the section shell (ABS-101W-FA818); the tool also tries SEC_NAME and strips a trailing -{SEC_TERM} when present.
  • Org unit ID: If the CSV includes a Brightspace OrgUnitId, that is checked first against the semester’s offerings.
  • Legacy columns: SEC_DEPTS + SEC_COURSE_NO + SEC_NO are still supported when COURSE_CODE is empty.
