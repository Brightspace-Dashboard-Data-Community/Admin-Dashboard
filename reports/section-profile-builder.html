Section Profile Config Builder

Build section-instructors.json and resized instructor photos for multi-section courses, then publish to the course Manage Files root for the Section Profile Widget.

Admin use: search any course by org unit ID or code, map each section to an instructor, upload photos (auto-resized to 400×400 JPEG), and publish. Instructors can use the same builder from the Faculty Dashboard or a hidden course Content topic.
