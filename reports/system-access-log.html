System Access Log

Upload the Sunday full System Access Log plus any differential CSVs from Data Hub, then enter an OrgDefinedId. The report looks the user up in Brightspace and writes OrgDefinedId on the download.

FERPA: Session history is an education record. Use only for legitimate educational purposes at Your College.
Add the Sunday full extract and any daily differential CSVs, then enter an OrgDefinedId and click Search.
    Expected columns: SessionId, UserId, Timestamp, State, Source, AppVersion, Device, IsOfflineMode, IPAddress. You can select several files at once, or add more after the full dump. Duplicate rows that appear in both the full extract and a differential are kept once. Device, AppVersion, and IsOfflineMode are filled on Pulse (mobile) rows. Brightspace web rows leave those blank.
    Dates use Detroit local time. Leave them blank to keep every matching session. Source is typically Brightspace (web) or Pulse (mobile). Pulse rows include app version and device; Brightspace web rows leave those blank.
