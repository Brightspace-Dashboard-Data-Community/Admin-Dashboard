Sandbox Dummy Course Launcher

Build a 7-week Michigan History sandbox with content, gradebook, discussions, dropboxes, quizzes, and three dummy students — then download a student-work package for anything the API cannot post as those students.

How this launcher works

Tab 1 talks to Brightspace and creates a full dummy course. Tab 2 builds files you can upload while impersonating each dummy student, plus Brightspace CSV quiz questions (the API can create quizzes, but not questions).

Course theme: Michigan History, 7 weeks. Each week includes a webpage, PowerPoint, PDF, Word file, and a YouTube link. Gradebook uses a points system with 9 items. Discussions, dropboxes, and quizzes are capped at 3 each.
Limits the API cannot cross: quiz questions cannot be created through Valence, and dropbox/discussion work cannot be submitted as another user. Tab 2 packages those materials so an admin can impersonate each dummy student and upload on their behalf, then import the CSV into Question Library and add questions to each quiz.

Push the limits: student work + quiz questions

Brightspace will not let the API submit dropbox files or discussion posts as another user, and it will not create quiz questions. This tab builds a zip you can use while impersonating each dummy student, plus CSV files for Question Library import (5 questions per quiz).

Load a course to see dummy students, dropboxes, discussions, and quizzes. Tab 1 results are remembered in this browser.

How to use the zip

  1. Open the course classlist and impersonate a dummy student (Ada, Lansing, or Marquette ZZSandbox).
  2. Upload that student’s dropbox Word files to the matching assignment folders.
  3. Copy each discussions text file into the matching discussion topic.
  4. Stop impersonating. In Question Library, import each quiz CSV (or ALL-QUIZZES.csv), then add those questions to the matching quiz.
