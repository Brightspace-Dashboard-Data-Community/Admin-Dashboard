User Adds & Drops Audit (Insights)

Upload the Ellucian Insights Roster Adds and Drops CSV to find enrollment mismatches against D2L.

How to Use This Tool

What this is: a duplicate of the original User Adds & Drops Audit, rebuilt for the new Ellucian Insights report that replaces SSRS. The original tool is left untouched.

Step 1: Prepare the CSV File

Run the Ellucian Insights Roster Adds and Drops report and export it to CSV. Status codes A, N mean enrolled; D, X, NP, C mean dropped.

Expected CSV Columns (Insights export):

  • term - Semester/term identifier (e.g. 26/FA, 26/SP)
  • person_id - Student ID, same as D2L OrgDefinedId (leading zeros handled automatically)
  • status - Enrollment status (only A / N appear)
  • stc_status_date - Date of status change
  • first_name, last_name, delta_email - Student name & email
  • sec_title, course_name, section - Course info
  • sec_name - Section key used to match D2L (e.g. MTH-119W-SS310)
  • faculty_id, faculty_name - Present in export but not used by this tool

Step 2: Run the Audit

Upload the CSV, optionally filter by term (defaults to current terms 26/FA and 26/SP), and click "Start Audit." Each row is compared against D2L using the same method as the original Adds & Drops tool. Include both terms in the Insights export if you want Fall and Spring/Summer audited together.

Step 3: Review & Hand Off to OIT

The results table shows only mismatches — students whose D2L enrollment does not match the CSV. Click "Download CSV" to export the change list to send to OIT.

⚠️ Important Notes:

  • Status codes: A, N = should be enrolled; D, X, NP, C = should be dropped
  • person_id is the same as D2L OrgDefinedId (leading zeros handled automatically)
  • Rows are deduplicated by person_id + sec_name + term, keeping only the most recent stc_status_date
  • sec_name is matched against D2L course Codes (e.g. MTH-119W-FA310-26/FA, MTH-119W-SS310-26/SP)
  • Only Student role (RoleId 101) enrollments in Course Offerings are checked
  • This tool is evaluation only — it does not enroll or drop anyone in D2L
