Homepage Audit by Semester

Identifies course offerings that are NOT using the Default homepage and/or have an old homepage listed (My Course - Jon's Homepage).

How to Use This Tool

Purpose

This tool audits course offerings by semester to identify:

  • Courses NOT using the Default homepage
  • Courses that have the old "My Course - Jon's Homepage" listed (even if not active)
  • Courses actively using the old "My Course - Jon's Homepage"

Steps

  1. Select Semester: Choose the semester you want to audit from the dropdown
  2. Click "Run Audit": The tool will check each course offering's homepage settings
  3. Review Results: The results table shows detailed information for each course
  4. Download CSV: Export the complete audit results as a CSV file

Report Columns:

  • OrgUnitId: The course offering's organization unit ID
  • Course Name: Full name of the course
  • Course Code: Course code/identifier
  • ActiveHomepageText: The currently selected homepage
  • IsDefaultHomepage: Whether the Default homepage is active (Yes/No)
  • HasJonsHomepageListed: Whether the old homepage appears anywhere on the page (Yes/No)
  • ActiveIsJonsHomepage: Whether the old homepage is currently active (Yes/No)
  • HomepageSettingsURL: Direct link to the course's homepage settings
  • HomepageSettingsURL: Direct link to manually switch the homepage in Brightspace

⚠️ Important Notes:

  • The audit may take several minutes for large semesters - watch the progress indicator
  • Courses are checked sequentially to avoid rate limits
  • If a course returns an access error, it will be marked as ERROR and the audit will continue
  • You can stop the audit at any time using the Stop button
  • After the audit completes, use the HomepageSettingsURL links to manually switch courses to the default homepage in Brightspace
