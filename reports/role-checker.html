Role Checker Report

This tool compares a faculty assignment CSV to live Brightspace enrollments and identifies faculty who are not Instructor on org 1001, so you can bulk-update them.

How to Use This Tool

Step 1: Export the faculty list as CSV

Use the current faculty assignment export (Excel or Insights). If it is an Excel file, save or export it as CSV first. The first row must be headers. Required and used columns:

Expected columns:

  • Full Faculty — OrgDefinedId (required). Example: 1200009
  • faculty_name — Display name in Last, First format (optional). Example: Bamberg, Justin R

Example header row:

Term,Section,Status,Full Faculty,faculty_name,Division,Depts,Course Number,"Combined Depts, Course Number, Section, Term"

The same instructor often appears on multiple section rows. The tool de-duplicates them by Full Faculty before comparing to DataHub.

Step 2: Upload and Analyze

Upload the CSV and click "Analyze Faculty Roles". The tool looks up each unique OrgDefinedId in Brightspace and checks their enrollment on org 1001.

Step 3: Review Results

The results table shows faculty who are Student (101), not enrolled on 1001, or enrolled as some other role. Student and missing enrollments are selected by default.

Step 4: Update Roles (Optional)

Click "Bulk Update Selected to Instructor" to set the selected users' org-level role on 1001 to Instructor (102).

Important notes:

  • Analysis uses live Brightspace user and enrollment APIs (not Data Hub), so results match current org 1001 status
  • Large faculty lists take a few minutes because each unique ID is checked individually
  • Updates are made to the org-level role on org unit 1001
