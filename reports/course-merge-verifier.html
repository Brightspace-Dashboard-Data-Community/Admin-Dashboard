Course Merge Verifier

Verify course merge requests by checking course codes, Delta ID Number, enrollment status (ACTIVE/CXLD), and instructor assignments.

How to Use This Tool

Step 1: Prepare Zoho CSV File

Export the course merge request data from Zoho as a CSV file.

Required CSV Columns (case-insensitive):

  • Name - Submitter's name
  • Email - Submitter's email
  • Delta ID Number - Instructor's Delta ID (matched against D2L OrgDefinedId)
  • Division - Division/department
  • Master course - The master course code
  • Merging course… - One or more columns starting with "Merging course" containing course codes to merge

Each row is verified against D2L with Yes/No columns for: Courses Found, Courses Active, Not CXLD, User Resolved, Delta ID Match, and Instructor Role (102). Pass is Yes only when every check passes. Failed rows include a Failure Reason explaining which check(s) failed and on which course.

Step 2: Select Semester and Upload CSV

Choose the semester from the dropdown, upload your Zoho CSV file, and click "Run Verification" to verify merge requests.
