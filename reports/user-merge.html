Merge Duplicate Users

Combine two Brightspace user accounts with the July 2026 User Merge API (POST /d2l/api/lp/1.62/users/merge). This is not a course-section merge and is not related to Office Hours Chat. For combining course sections, use Course Merge Verifier / Course Merge Updater.

What this does: selected data from the source (duplicate) account is copied onto the destination (keep) account. Direct enrollments can transfer; cascading enrollments and class progress do not. The source account is then deactivated (default) or deleted. Requires Brightspace permission Users > Can Merge Users and LP API 1.62+ (July 2026 / 20.26.7).
