MERGED Course Classlist → Simple Syllabus Use

This report is specifically designed to support Simple Syllabus merged enrollments so that students can access the correct syllabus in merged course offerings.

Purpose and Usage

This report is intended solely for preparing CSV files used to manage Simple Syllabus merged enrollments for students. It is not a general-purpose enrollment or classlist reporting tool.

  1. Generate the CSV: Select a semester and click "Generate CSV". The report will:
    • Find all MERGED course offerings in the selected semester
    • Extract CRNs from each merged course's sections
    • Match those CRNs to find the corresponding Primary course
    • Export student-only classlist data with both merged and primary course information
  2. Verify the Content: Open the downloaded CSV file and review the data:
    • Check that course_section_merged and course_section_merged_name show the merged course information
    • Verify that primary_section and primary_section_name correctly match the primary course for each row
    • Ensure person_id (OrgDefinedId) and role_name are correct
  3. Format for Upload: After verifying the content, you need to format the CSV for upload:
    • Remove the columns: course_section_merged, course_section_merged_name, and primary_section_name
    • Rename primary_section to course_section
    • Keep only these columns: active, role_name, person_id, course_section
    • Save the formatted file with a new name (e.g., merged-classlist-formatted.csv)
  4. Upload the Formatted CSV: Use the formatted CSV file to upload enrollments. Note: View screen recording demonstrating the upload process for reference.

Example: The original CSV has columns: active, role_name, person_id, course_section_merged, course_section_merged_name, primary_section, primary_section_name

The formatted CSV should have: active, role_name, person_id, course_section (where course_section contains the values from primary_section)
