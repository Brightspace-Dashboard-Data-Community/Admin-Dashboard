Grade Submission Assessment Generator

Upload a grade-submission-report.csv file to generate the Word assessment report.

How to Use This Tool

Step 1: Prepare CSV File

Download or export the grade submission report as a CSV file. This CSV should contain course and grade submission information.

CSV File Requirements:

  • File should be named grade-submission-report.csv (or similar)
  • Must contain course and grade submission data
  • Should be exported from your grade submission reporting system

Step 2: Upload and Generate

Upload the CSV file and click "Generate Assessment Report" to create a formatted Word document.

⚠️ Important Notes:

  • Ensure your CSV file matches the expected format
  • The report generation may take a moment for large CSV files
  • The Word document will be automatically downloaded when ready
