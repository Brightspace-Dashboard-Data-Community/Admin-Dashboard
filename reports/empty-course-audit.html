Empty Course Audit

Audits selected semester's course offerings (excluding MERGED, CXLD, Sandbox) for news, content, and grades.

How to Use This Tool

Step 1: Prepare Simplified Courses CSV (Optional)

The CSV is optional but recommended. It provides start/end dates (and faculty name as a fallback). If not provided, the audit will still run but start/end dates will be blank.

CSV Format Requirements:

  • Combined course code: Combined Depts, Course Number, Section, Term — e.g. ART-111-FA100-26/FA
  • Dates: Start Date and End Date (prefixed names like course sec meetings simplified → Start Date are fine)
  • Optional: faculty_name (used only if D2L has no instructor on the classlist)

The term suffix (-26/FA) is stripped when matching D2L. Legacy SEC_NAME / SEC_START_DATE / SEC_END_DATE files still work.

Step 2: Run the Audit

  1. Upload CSV (Optional): If you have the simplified courses CSV, upload it using the file input
  2. Select Semester: Choose the semester you want to audit from the dropdown
  3. Click "Run Audit": The tool will check each course for news, content topics, and grade items (ignoring Final Calculated Grade and Final Adjusted Grade)

Step 3: Review Results

The results table shows course status, instructor information, and dates. You can paginate through results and download the complete audit as CSV.

⚠️ Important Notes:

  • A course is Empty only when it has no news, no content topics, and no grade items besides Final Calculated Grade / Final Adjusted Grade. The preloaded Student Success Modules folder is ignored.
  • Courses are checked in batches - results appear incrementally
  • Instructor role is identified as RoleId 102 (Instructor)
  • MERGED, CXLD, and Sandbox courses are automatically excluded
