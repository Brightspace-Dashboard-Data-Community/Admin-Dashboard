End of Semester Course Report WIP

Work-in-Progress. Class-level retrospective of grades, access, content, due dates, quizzes, discussions, and assignments, with next-term suggestions. No student names. Last-access timing is measured from the course end date, not from today. This copy requests Content Progress and Learner Usage from Data Hub (Advanced Data Sets), which faculty cannot execute.

Build a report

Enter a course offering OrgUnit ID. The report pulls Brightspace gradebook, assignment, quiz, discussion, content, and last-access data, then also creates Data Hub jobs for Content Progress and Learner Usage, unzips the CSV in the browser, and matches rows to this course. Names from those files are not shown. If Data Hub is not permitted, the report falls back to Brightspace content APIs.
