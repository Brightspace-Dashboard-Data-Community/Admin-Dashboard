Enrollment watch list

Classlist for a course or 26FA-style semester offering, then enrollment logs since the last successful run (June 2026 /users/{id}/enrollmentlogs/). Built for SIS/ILP “what changed overnight?” — enrolls and drops, with who performed them. Not a course-section merge and not Office Hours Chat.

The API is per user, not org-wide. This tool snapshots each course’s classlist in this browser so the next run can still see people who were dropped. First run on a course only sees people still enrolled; the next run catches overnight adds and drops.
