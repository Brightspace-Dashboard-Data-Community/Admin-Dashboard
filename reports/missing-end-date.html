Courses Missing Start or End Dates

Find and fix courses that are missing start or end dates in D2L.

How to Use This Tool

Step 1: Select Semester

Choose the semester you want to audit from the dropdown menu.

Step 2: Run Report

Click "Run Report" to scan all courses in the selected semester for missing start or end dates.

Step 3: Fix Missing Dates

You can fix missing dates individually or in bulk. End dates are set to end of today, and if start date is missing, it's set to yesterday.

⚠️ Important Notes:

  • End dates are set to the end of today (00:01 UTC)
  • If a course is missing both dates, start date is set to yesterday
  • Date changes are permanent - ensure you want to update before bulk fixing
