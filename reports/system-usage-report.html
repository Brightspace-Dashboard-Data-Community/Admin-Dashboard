System Usage Analytics

Quantify adoption and activity across Brightspace for a selected semester. Use tabs to switch summaries.

About this report

What this pulls:
• Unique logins by day (from login/last-access sources).
• Active courses accessed per day.
• Recency buckets (≤7d, >30d) for user logins.
• Optional tool indicators: Content views, Quiz attempts, Discussion posts.
Select a semester and click Run to populate the table.
