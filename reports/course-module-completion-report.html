Course Module Completion

Per-student topic completion for one course offering: one learner by Org Defined ID, or everyone on the classlist. Uses Brightspace content completion data.

Run report

Requires completion tracking on course topics. Run this tool while signed into Brightspace in the same browser (same origin as the APIs). Classlist mode calls the completion API for every topic × every learner and can take several minutes on large sections.
If your org maps faculty to other role IDs, choose “Everyone” or ask for an expanded filter.
Used only for single-learner scope.
What this uses

Course TOC from LE Content, then each topic’s completion record per user. Classlist mode loads enrollments from the classlist API, then repeats those checks for each member. If a topic has no completion record or your role cannot read it, that row shows as not completed.
