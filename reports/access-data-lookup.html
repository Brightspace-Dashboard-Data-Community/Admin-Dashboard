Access Data Lookup

Look up System Login/Access via the live D2L API (date range) or by uploading a User Logins CSV. Course Access still uses the Course Access CSV export. Enter a UserId directly, or use Username or OrgDefinedId to resolve the user automatically.

Data Source
Calls /d2l/api/lp/1.61/users/{userId}/usertrackinglogs/ for successful logins. Each selected day uses 12:00:00.000 AM through 11:59:59.999 PM (UTC). The API allows a maximum of 31 days.
Upload a User Logins CSV export, then enter a user identifier and click Search.
Large files are streamed without loading all rows into memory.
Results show Student ID (OrgDefinedId), Username, IP, and Attempt Date in Detroit time.
