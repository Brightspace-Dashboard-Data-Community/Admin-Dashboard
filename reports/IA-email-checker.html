Intelligent Agent Reply-To Audit — CSV-First

Choose a semester → load offerings (excludes MERGED/CXLD) → upload IA CSV → we audit only courses whose agents are Enabled. If Reply-To is empty/default, we pull instructor emails from Classlist for outreach.

How to Use This Tool

Step 1: Load Semester Courses

  1. Select Semester: Choose the semester from the dropdown.
  2. Click "Load Semester": The tool will:
    • Load all course offerings in the semester.
    • Exclude courses with "MERGED" or "CXLD" in the code.
    • Display the count of courses found.

Step 2: Upload IA CSV

Upload a CSV file containing Intelligent Agent settings for courses.

CSV Requirements:

  • Must contain OrgUnitId column (or will auto-detect).
  • Must contain Enabled column (or will auto-detect).
  • Only courses with Enabled=TRUE will be audited.
  • The CSV should be exported from your Intelligent Agent reporting system.

Step 3: Build Target List

After uploading the CSV, click "Build Target List" to:

  • Match CSV rows with semester courses by OrgUnitId.
  • Filter to only courses where Intelligent Agents are Enabled.
  • Display the count of target courses to be audited.

Step 4: Run Audit

Click "Run Audit" to check Reply-To settings:

  • For each enabled course, checks the Intelligent Agent Reply-To field.
  • Compares against optional default email (if provided).
  • If Reply-To is empty or matches default, pulls instructor emails from Classlist.
  • Displays results showing which courses need Reply-To updates.

Step 5: Review and Download

The results table shows:

  • Status: Custom (overridden), Default (unchanged), or Empty.
  • Instructor Emails: Shown for courses with empty/default Reply-To.
  • Fix: Action needed for each course.

You can download results as CSV for further processing or outreach.

⚠️ Important Notes:

  • Only courses with Enabled=TRUE in the CSV are audited.
  • The audit may take several minutes for large datasets – watch the progress bar.
  • Instructor emails are pulled from classlist for courses needing Reply-To updates.
  • You can provide a default email for comparison (optional).
  • Download results for outreach to instructors about Reply-To settings.
