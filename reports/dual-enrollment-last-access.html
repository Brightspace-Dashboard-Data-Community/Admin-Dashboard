Dual Enrollment Last Access

Upload a CSV of student OrgDefinedId values, pick a semester, and scan 7xx / 8xx dual-enrollment sections from the Course Name (for example HEALTH CARE ETHICS - PHL-215W-FA820/FA830/FA840-26/FA). Child offerings titled MERGED - are skipped so each student appears on the academic course once.

This report reads Course Name, not Course Code. Merged parents keep every section in the name (FA820/FA830/FA840) while the code often stays on a single section. Offerings whose name starts with MERGED - are ignored. The scan keeps courses whose name includes the selected term (such as 26/FA) and a 7xx/8xx token. Course last access comes from Brightspace classlist / access APIs. Org-level D2L login uses the same LastAccessedDate as Search User. Course start and end dates come from the simplified courses CSV when you upload it.

Student CSV may be a single column of IDs, or a file with a header named OrgDefinedId, person_id, or Student ID. Leading zeros are tried automatically. Upload the same simplified courses file used by Empty Course Audit (Combined Depts, Course Number, Section, Term, Start Date, End Date) to fill course dates.
