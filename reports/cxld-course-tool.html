Cancelled Course Tool

Compare D2L courses with College CSV files and process course cancellations in bulk.

How to Use This Tool

Part 1: Download the simplified courses CSV

Upload the simplified college CSV (one combined course code per row). Extra columns are ignored.

Required CSV columns:

  • Combined Depts, Course Number, Section, Term — e.g. ART-111-FA100-26/FA
  • Status — C = cancelled; other values (e.g. A) = active

Prefixed headers such as course sec meetings simplified → Status are accepted. The term suffix (-26/FA) is stripped when matching D2L course codes. Legacy Depts / Course Number / Section / SEC_* files still work.

Part 2: Run CSV Through the Admin Dashboard

Use Tab 1 to compare courses, download the comparison report, then use Tab 2 to process cancellations in bulk.

⚠️ Important Notes:

  • Always preview before processing cancellations
  • Course code changes are permanent - ensure your CSV file is accurate
