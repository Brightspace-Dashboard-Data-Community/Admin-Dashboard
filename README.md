# Admin Dashboard

Browser-based Brightspace admin dashboard for user and course lookups, enrollments, and reports.

Values that identify a single college are placeholders in this copy:

- Brightspace host: `your-brightspace.example.edu`
- Email domain: `example.edu`
- Organization name: Your College
- Institution org unit: `1001`
- Orientation org unit: `1000001`

Replace those placeholders before deploying. Do not add live user exports, staff directories, screen recordings, or production widget copies to this repository.

See `CHANGELOG.md` for changes after the GitHub baseline.
