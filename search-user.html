How to Search

Please ensure you are using the correct identifier type for your search:

  • ID Number (OrgDefinedId): This is the user's specific organization ID (e.g., "1535209").
  • Username: Requires an exact match string (e.g., "johnsmith"). If no exact match is found, the system will automatically search by name (First/Last name).
  • User ID: The internal numeric identifier for the system (e.g., "157").
  • Name Search: When searching by Username, if no exact match is found, the system will automatically search by first or last name. For example, searching "Justin" will find all users with "Justin" in their first or last name.
