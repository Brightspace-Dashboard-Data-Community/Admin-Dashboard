A guided tour of every main area in the sidebar. About 10 minutes the first time — use the table of contents if you only need one section.

1. How to use this dashboard

The Admin Dashboard is a Brightspace-connected hub for the eLearning team. It does not replace Brightspace Admin Tools — it sits beside them.

  • Use the left sidebar to move between sections. The hamburger icon collapses or expands the menu.
  • Your name appears at the bottom of the sidebar when you are signed in through Brightspace.
  • Many pages read live data from Brightspace using your session — stay signed in.
  • Report pages that need Data Hub extracts only load that data when you open them, not from Home.
  • On deeper pages, look for a Back to Dashboard link above the title to return.

2. Home

Orientation and shortcuts — not live instance charts.

  1. Open Home to see frequently used tools and jump links into each major area.
  2. Use Search a user when you need a lookup first.
  3. Use Browse reports & tools when you need audits, merges, or utilities.

Open Home

3. User Management

Find and maintain Brightspace user records. Expand User Mgt in the sidebar.

  • Overview — when to use which user tool, plus quick report access.
  • Search User — lookup by name, username, or Org Defined ID. Start here for most tickets.
  • Create User — add an account that is not coming from SIS.
  • User List — browse users when you do not have a specific search term.
  • Merge Users — combine duplicate Brightspace logins (not course sections).

Open User Overview

4. Course Management

Find offerings and create practice or empty shells. Expand Course Mgt in the sidebar.

  • Overview — when to use which course tool, plus quick report access.
  • Search for Courses — look up an offering, sandbox, or org unit.
  • Create a Sandbox — provision a practice course for an instructor.
  • Create a Course Shell — make an empty offering when SIS has not created one.
  • View Course List — browse courses for a semester.

Open Course Overview

5. Enrollment Management

Add or change course enrollments. Expand Enroll Mgt in the sidebar.

  • Overview — when to use which enrollment tool, plus quick report access.
  • Create Enrollment — add one person to one course with a role.
  • Manage Enrollment — review or change existing enrollments.
  • Bulk Enrollment — enroll many users at once from a list.

Open Enrollment Overview

6. Faculty Success

New instructor onboarding for the eLearning team. Expand Faculty Success in the sidebar.

  • Command Center — unified hub for records, meetings, and status.
  • New Instructor Intake — create onboarding files for newly created instructors.
  • Communication Hub — Outlook email templates for outreach.
  • Automation Runner — run onboarding automations in batches.
  • Leadership Report — pipeline metrics and CSV exports.
  • Faculty Not in Orientation — instructors missing the Faculty Orientation course.
  • Action Queue — records that still need attention.

Open Command Center

7. Reports & Tools

Operational audits and utilities. Open the full catalog from the sidebar, or start with the featured items on Home.

  • Reports & Tools catalog — every report and utility grouped by area.
  • Empty Course Audit — shells with no content.
  • Adds & Drops Audit — recent enrollment changes.
  • Course Merge Verifier and Course Merge Updater — section associations.
  • Cancelled Courses — CXLD offering cleanup.
  • Retirement, inactive accounts, and user-merge workflows are listed further down the catalog page.

Open Reports & Tools

8. Division Info

Reference data for academic divisions — not live course metrics.

  1. Open Division Info.
  2. Use it when a ticket needs a dean, associate dean, or division grouping.

Open Division Info

9. Tutorials

Staff-facing walkthroughs for common Brightspace and dashboard tasks.

  1. Open Tutorials.
  2. Use these when you are showing a process to a colleague or documenting a step.

Open Tutorials

10. Suggested next steps

A practical path for the first visit.

  1. Bookmark Home — it is the map, not the analytics page.
  2. Try Search User with a known Org Defined ID so you know the lookup works in your session.
  3. Open Command Center if you work new-instructor tickets.
  4. Skim the featured section on Reports & Tools for Empty Course Audit, Adds & Drops, and Course Merge.
  5. Need help? Submit a ticket through the Help Desk Ticketing System.
